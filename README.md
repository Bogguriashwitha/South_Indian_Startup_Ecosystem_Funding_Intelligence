# South Indian Startup Ecosystem & Funding Intelligence Dashboard

## Project Overview

This project analyzes startup funding trends in India, with a focus on major startup cities and sectors relevant to the South Indian ecosystem.

The dashboard helps understand funding trends, deal activity, sector performance, city-wise funding, and funding volatility.

## Tools Used

- Python
- Pandas
- MySQL
- Excel
- Power BI

## Key Analysis

- Year-wise funding trends
- City-wise funding analysis
- Sector-wise funding analysis
- Funding concentration
- Year-over-year funding growth
- Deal-size volatility by sector

## Dashboard Pages

### 1. Executive Overview
Provides an overall view of total funding, total deals, average deal size, yearly funding trends, and sector funding.

### 2. City & Sector Intelligence
Analyzes funding and deal activity across cities and sectors.

### 3. Risk & Volatility Monitoring
Highlights funding volatility and changes in funding trends over time.

## Key Findings

- Bengaluru is the leading city by total funding in the dataset.
- Funding varies significantly across years.
- E-Commerce is one of the major funding sectors.
- Funding is concentrated among a relatively small number of sectors.
- Deal-size volatility differs considerably across sectors.
